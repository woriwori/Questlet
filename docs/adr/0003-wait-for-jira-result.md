# 사용자 저장은 Jira 결과까지 기다리고 같은 화면에서 안내한다

emux를 제거하고 Jira 직접 호출의 응답이 빠르다는 사용자 확인에 따라, 폼 저장과 코멘트 추가는 로컬 저장 후 Jira 반영 결과까지 기다리기로 변경했다. 처리 중에는 화면을 응답 가능하게 유지하고, 성공·실패·응답 시간 초과를 같은 화면에서 안내해 별도 알림 기능을 제외한다. 로컬 변경 유지와 중단된 요청 복구는 계속 제공하며, 매일 자동 상태 갱신은 백그라운드 반영과 앱 상세의 오류 표시로 처리한다.

ADR-0002의 사용자 입력에 대한 백그라운드 완료 안내 방식을 대체한다.
