# Mac 전용 앱을 SwiftUI로 구현한다

2026-10-03에 사용자는 Swift와 Electron 중 가벼움, 유지보수 용이성, 구조 단순성을 우선해 선택하도록 위임했다. Mac 전용 메뉴바 앱이므로 SwiftUI와 필요한 범위의 AppKit을 선택한다. Electron의 Chromium·Node.js 런타임과 메인·렌더러 통신을 추가하지 않고, UI와 로컬 기록·Jira 연결을 하나의 네이티브 앱에서 관리한다.

기존 사내 Electron 테스트 앱은 비교 맥락이며 이번 프로젝트에서 재사용하도록 요청받지는 않았다. 웹 기술 재사용이나 다른 운영체제 지원이 중요해지면 이 결정을 재검토한다. 날짜 범위 선택 UI는 별도 구현이 필요하며 SwiftUI가 이를 자동으로 제공한다고 가정하지 않는다.
