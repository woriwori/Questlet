# 로컬 기록을 먼저 저장하고 Jira에 비동기로 반영한다

느린 사내 emux 응답이 확인된 변경의 저장을 지연시키지 않도록, Mac 앱이 사용자 확인과 로컬 저장을 담당하고 Jira 반영은 백그라운드에서 수행한다. Jira 실패 시에도 로컬 변경을 유지하고 반영 실패를 표시하며, 재실행 시 재개할 수 있도록 미처리 요청을 로컬에 보존한다. Jira에서 로컬로 가져오는 동기화는 제외하고, 자연어 처리에 필요한 데이터만 emux에 전달하며 로컬 DB 자체의 외부 저장·동기화는 하지 않는다.
