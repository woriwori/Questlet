# 2026-10-24 실제 Mac E2E 재검증

잠금 때문에 미검증으로 남았던 항목을 Mac 잠금 해제 후 Computer Use의 실제 클릭·키 입력·휠 조작으로 확인했다.
자동 검사 또는 렌더링만으로 통과 처리하지 않았다.

## 환경과 설치

- Apple Silicon Mac, macOS 26.6.2. 설치 검증 시점의 소스 커밋은 `c0ef180`이다.
- 이전에 실행 중이던 앱은 코멘트 수정 전 버전이었다. 빈 입력 상태를 확인하고 정상 종료했다.
- 저장소 루트에서 `bash scripts/install.sh`를 실행했다. 종료 코드 0, `설치 완료:` 출력을 확인했다.
- `~/Applications/Questlet.app`의 서명 검사가 성공했고, 해당 경로의 실행 프로세스와 실제 메인 화면을 확인했다.
- 개발용 dist 앱과 설치 앱이 같은 bundle ID이므로 Computer Use는 설치 앱의 전체 경로로 지정했다.

## 데이터 보존과 재현

- 사용자가 재검증 중 작성한 코멘트 초안은 보존했다. 테스트 문장과 테스트용 개행만 제거해 원래 내용으로 복원했다.
- 추가 버튼을 누르지 않았으며 실제 티켓의 등록된 코멘트 수는 0개 그대로다. 토큰 변경과 작업 삭제도 수행하지 않았다.
- 100개 작업은 `./scripts/check-ui.sh --show-sidebar`가 만드는 임시 DB의 별도 창이다. 사용자 DB에 테스트 작업을 추가하지 않았다.
- 테스트 창은 검증 후 종료했다. 설치된 실제 Questlet은 실행 상태로 유지했다.
- 실제 화면 캡처는 채팅의 outputs 폴더에만 보관하며 사용자 티켓 제목이나 초안 이미지는 저장소에 커밋하지 않는다.

이 검증은 위 항목의 화면 동작과 이 Mac의 설치·실행 범위다. Intel Mac 실행, 실제 사내 API 쓰기와 코멘트 등록 요청은 이번 검증에 포함하지 않았다.
