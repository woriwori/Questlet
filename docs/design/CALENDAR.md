# Questlet 캘린더 제안 · 2026-10-19

## 선택: 기존 창 위의 월간 시트

목적은 작업을 보다가 일정과 겹치는 작업 수를 잠깐 확인하는 것이다. 월간 시트는 기존 목록·선택·검색을 유지하고 닫자마자 복귀할 수 있다. 전용 화면은 일정 드래그나 주간 시간표처럼 넓은 편집 공간이 필요해지면 검토한다.

## 디자인 계획과 검토

기존 Mac 시스템 글꼴과 연한 중성 톤을 유지한다. 배경 #FCFCFC, 날짜 배경 #F4F5F6, 제목 #282D33, 보조 텍스트 #6E747C, 오늘 #56729A, 진행 표시 #4F89BC. 제목 18pt semibold, 날짜 12pt, 개수 10pt, 안내 11pt다.

```text
Questlet                    2026/10/19 [달력] [설정] [+]
           ┌─────────────────────────────────┐
           │ 2026년 10월       [오늘] ‹ › × │
           │ 일   월   화   수   목   금   토 │
           │           …                     │
           │ 18  (19) 20   21   22   23   24 │
           │ •2   •5  •4   •3   •2   •1     │
           │           …                     │
           │ • 날짜별 진행 작업   조작 안내  │
           └─────────────────────────────────┘
```

600pt 너비, 24pt 여백이다. 연·월은 왼쪽, 오늘·월 이동·닫기는 오른쪽이다. 6주 고정 높이로 월 이동 시 화면이 흔들리지 않게 한다. 작업명 카드나 색 띠 대신 점 하나와 개수 하나로 정보를 압축해 기존 상태 점 디자인과 맞춘다.

실제 SwiftUI 컴포넌트를 샘플 데이터로 렌더링하고 5개 작업일의 압축 표시, 간격, 아이콘 위치를 확인했다. 제안 이미지의 딤·그림자는 렌더링용 배경이며 실제 앱에서는 macOS 기본 시트가 배경과 표시 방식을 관리한다.

## 동작

- 날짜 오른쪽에 SF Symbol calendar를 표시한다. 설정과 같은 16pt glyph, 32pt 클릭 영역이다.
- 검색·상태 탭과 독립적으로 전체 로컬 작업을 읽는다. 해당 날짜가 시작일 이상·종료일 이하인 작업을 표시한다. 오늘 진행 중인 작업만 다른 월에 복제하지 않는다. 과거 완료·미래 예정 작업도 각자의 기간에 나타난다. 티켓 ID 없는 작업도 포함한다.
- 작업 없는 날은 날짜만, 있는 날은 점 하나와 개수만 표시한다. 작업이 5개든 50개든 날짜 칸 높이는 같다.
- 마우스오버 기본 툴팁에 날짜와 전체 작업명을 이름 오름차순으로 표시한다.
- 클릭 시 스크롤 가능한 목록을 연다. 긴 이름은 줄바꿈하며 티켓 ID가 있으면 함께 표시한다. 항목 선택 시 달력을 닫고 해당 작업 상세로 이동한다.
- 이전·다음 달, 오늘, 닫기, Esc를 제공한다. 그냥 닫으면 기존 목록·선택·검색·정렬을 유지한다.
- API 요청·DB 변경·드래그 편집은 없다.

## 연결 지점과 검증

- TaskViews.swift: 상단 아이콘과 시트 표시.
- WorkCalendarView.swift: 월간 화면, 툴팁, 날짜 클릭 목록과 상세 이동.
- QuestletCore/WorkCalendar.swift: 한국 시간 월 구성·6주 달력·월 이동·기간 포함 판정.
- scripts/check.sh: 윤년, 일요일 시작, 연도·월 경계, 시작·종료일 포함, 완료 작업의 해당 날짜 표시, 빈 목록과 기존 흐름.
- scripts/check-ui.sh --render-calendar <PNG 경로>: 임시 DB 샘플로 구현 UI 렌더링. 사용자 DB·PAT는 사용하지 않는다.

실제 마우스 hover, 네이티브 시트 표시·Esc·중첩 팝오버 선택은 자동 UI 조작으로 검증하지 않았다. 렌더링·컴파일·날짜 로직 검사는 완료했다.
